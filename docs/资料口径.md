# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

pledge是承诺，receipt是实际资源，receipt.pledge_value_units为合同认可的兑现额；declared_value仅声明，acquisition_value为取得价值，presentation_value只作展示，不替现金。cash receipt转purchase所取得物资不再计donation receipt。change_id明确承诺现金改物资份额，不能同时计原现金份额未履行和替代新承诺。受限用途按resource的purpose及明确变更，若已用份额不符新用途，保留事实和差额，不重贴标签。partner_claim为资源使用主张而非额外消耗，所有合作方同资源主张不得超实际取得份额。dispatch到partner是代管，beneficiary_receipt才是终交；unopened_return可恢复物资，consumed voucher作废不恢复券。运费单列expense，不作受助物量。

## later_purpose_changes
后续用途修订只在明确范围生效，已用不抹除。

记录键：['change_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| change_id | string | 改 |
| resource_id | string | 资源 |
| new_purpose | string | 用途 |
| effective | datetime | 生效 |
| applies_to_existing | boolean | 及既有资源 |

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。下面标为后续接收的文件不随基础资料自动生效，用户可分次装载。历史事实的业务时点与本次接收时点分开。金额除另述外人民币元，结算舍入到分的尾差归该账单分摊基数最大项，并列按业务键升序。本文规定来源语义，不规定待开发仓表、算法或架构。

同一资源多个合作方主张在同一activity按credit_allocations明确认可份额才计合作方业绩，缺份额保留待分，不把不同合作方声称相加。credit_allocations是后续人工核实输入，当前未提供任何认可记录；其契约字段为allocation_id（唯一记录键）、resource_id、activity、partner、quantity（认可终交数量）、confirmed_at（带时区确认时刻），同键新文件为整行修订，认可数量总和不得超该资源活动已有终交数量。claim总和即使未超库存，也不能超已终交对应量。RC3 voucher_consumed才计服务，voucher_void若未消费从可用中撤销但不等同已消费恢复；需保留消耗与作废分别明细。
